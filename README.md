# Logistics & Bottleneck Analysis Dashboard 🚚📉

## Project Overview
This project is an enterprise-grade Power BI application designed to track supply chain bottlenecks, monitor SLA compliance, and calculate the exact revenue trapped in delayed shipments.

## 📊 The Business Problem & Insights
Standard supply chain reporting often fails to highlight the financial impact of delays. By engineering this dashboard, we uncovered the following actionable insights:

* **The Financial Bleed:** Identified **$8.1M** in revenue trapped in delayed shipments (orders > 10 days), accounting for 99.9% of total revenue loss.
* **Customer Churn Correlation:** The data proves a direct link between delivery time and churn. 1-star reviews average a **27.6-day** delivery time, while 5-star reviews sit at **16.5 days**.
* **Root Cause Identification:** "Children's Fashion" and "Furniture/Mattresses" were isolated as the primary product categories causing the backlog.

## 🛠️ Technical Specs & Features
Instead of standard reporting, this dashboard was built with a focus on premium UI/UX and advanced data modeling.

* **Dynamic Themes:** Engineered a seamless Light & Dark Mode toggle using page navigation and synced visual states.
* **Advanced DAX:** Built custom measures for dynamic SLA tracking and conditional formatting (red/green trend arrows).
* **Custom UI/UX:** Designed a collapsible "hamburger" navigation menu to keep the canvas clean while maximizing slicer accessibility.
* **Data Modeling:** Transformed flat raw data files into a fully functional relational model using Power Query.
